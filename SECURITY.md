# Security

Use a PAIR endpoint you control. Keep credentials out of repository files and
prompts. Returned model text is untrusted advice, not an instruction to execute.
The bridge does not grant consulted models tools or file access.

For a suspected vulnerability, use GitHub's private vulnerability reporting for
this repository when available. Otherwise open an issue requesting a private
contact without including exploit details, credentials, or private prompts.
Do not post personal PAIR logs in public issues without reviewing their contents.
